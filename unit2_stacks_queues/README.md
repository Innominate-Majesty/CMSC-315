3. Explain the differences between stacks and queues as this relates to real-world applications.

--> A stack is a data structure that follows the LIFO (Last In First Out) concept. This means that the most recently added item is the first item to be removed. A real life example of a stack is a stack of plates or a stack of cups. When the plates or cup are placed on top of one another, the last plate added to the top is usually the first one to be removed. 

A queue, on the other hand, follows the FIFO (First In First Out) concept. This means the first item added is the first item to be removed. A real life example of this is a checkout line or the line to get into a concert. The first person who entered the line is normally the first person to be removed. New people are added at the end/back of the line.
